# Cia-world-factbook-Editions
Most of the Editions are found here.

CIA World Factbook 2020 edition

The CIA took down their World Factbook on February 4th 2026 for unspecified reasons.

The Factbook has always been published in the public domain. They used to offer zip archives of previous years at URLs like this one (now a redirect to the shutdown notice):

https://www.cia.gov/the-world-factbook/about/archives/download/factbook-2020.zip

The 2011 to 2020 has been provided in this repository after recovery from the Internet Archive and used it to populate this GitHub repository.

The repository is served via GitHub Pages on link below:(2011-2024)
https://worldfactbook.co/
